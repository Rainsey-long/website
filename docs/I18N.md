# Language: English only

**Since 2026-10-05 the site is English only** (owner decision; DECISIONS.md). The Khmer language version that existed from 2026-10-04 was removed: the `/km` pages, the language switch, Khmer reading text, Khmer profiles, Khmer feeds and Khmer share images. Git history keeps it if it is ever wanted again.

## What stays

- **Khmer traditions**, written in English: the lunar calendar, holy days, festivals, Khmer New Year and its angel, birth-weekday colours.
- **Khmer terms inline**, wrapped so screen readers and fonts treat them as Khmer:

  ```tsx
  <p>Today is a Buddhist holy day, <span lang="km">ថ្ងៃសីល</span>.</p>
  ```

  Noto Serif Khmer loads only for those spans (unicode-range). The names come from `lib/khmer.ts` (`km` fields are tradition data, not translations). Check a Khmer term at 360px.
- **Old links keep working**: `proxy.ts` 308-redirects `/km` and `/km/<path>` to `/<path>` (absolute Location from `NEXT_PUBLIC_SITE_URL`).

## Writing strings

Co-located `defineMessages({ en: { … } })` and `T[lang]`, where `lang` is always `"en"` (`getLang()`, `useLang()`). The helpers are kept as thin scaffolding so pages did not need rewiring; new code may use them or plain strings.

## Why

Google's publisher products do not support Khmer, so a Khmer page could never carry ads (CamboMath's lib/ads.ts records the same), and one language halves the copy to write, review and keep in step.
